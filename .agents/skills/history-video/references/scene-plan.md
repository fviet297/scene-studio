# Scene plan — the skill input

> Some repos support multiple comparison projects side by side (see `scene-studio`). If a
> `projects/` directory exists, this file lives at `projects/<slug>/scene-plan.md` and
> character references at `public/projects/<slug>/characters/<id>.png` instead of the
> root-level paths shown below; everything else in this doc is unchanged.

The user writes **one markdown file**: the transcript split into scenes, each scene giving
just the **narration** (the transcript for that scene). One image per scene. The user does
**not** write the image prompt — the skill generates each scene's `prompt:` from that scene's
narration and writes it back into this file. Character reference images are **pasted by the
user** into `public/characters/<id>.png`. Everything else — title, cue, host pose, timing,
on-screen AI tag — the skill decides.

[scripts/parse-scene-plan.mjs](../scripts/parse-scene-plan.mjs) parses this into
`src/scene-plan.json` (one image per scene) and `scripts/narration-segments.mjs` (per-scene
TTS). The plan is the single source of truth for images, audio, captions, and timing.

## Format (minimal)

```md
# QUANG TRUNG vs HÀN TÍN

## characters

quang-trung = public/characters/quang-trung.png
han-tin = public/characters/han-tin.png

## scene 1

char: quang-trung, han-tin
narration: Một người là vị vua nổi tiếng của Tây Sơn. Một người là đại tướng khai quốc của nhà Hán...

## scene 2

char: quang-trung
narration: Nhà Tây Sơn nổi dậy, nhanh chóng tiến vào Thăng Long...

## scene 3

narration: Trung Hoa rơi vào nội chiến sau khi nhà Tần sụp đổ...
search: Chu-Han contention map
```

The user writes only `narration` (+ optional `char`/`search`). The skill then fills each AI
scene's `prompt:` from its narration (see **Prompt generation** below) and writes it back into
this same file, so a re-run keeps the generated prompts and the user can hand-edit any of them.

### Per scene

- **narration** (required) — the transcript for that scene; drives TTS + captions, and is the
  sole source the skill uses to write that scene's image prompt.
- **prompt** (written by the skill, not the user) — what the scene image shows. Generated from
  the narration and saved back here. Present on every AI scene after the skill runs; a user may
  hand-edit it. Absent on `search:` scenes.
- **char:** (optional) — one or more pasted-reference ids to keep consistent. With a `char:`,
  the image is generated by image-to-image from those references (identity preserved); without
  one, it is a plain 2D generation from the prompt. **Every id is uploaded**, in the order
  written: reference 1 is the first id, reference 2 the second, and the multi-character
  template locks each figure to its own. List every character the narration names.
- **search:** (optional) — source a real image for this scene instead of generating (use for
  maps, artifacts, real places). The skill does not write a `prompt:` for these scenes.
- **time:** (optional) — informational only; real scene length comes from the measured audio.

### Prompt generation (skill fills `prompt:` from `narration`)

For each AI scene the skill turns the narration into an image prompt under two rules:

- **Do not describe the character's appearance** (face, costume, build, hair). Identity comes
  from the pasted `char:` reference via image-to-image — restating looks fights the reference.
- **Describe only the character's action and gesture**, matched to what the narration says in
  that scene (marching, pointing across a map, raising a sword, kneeling, addressing troops),
  plus setting/atmosphere/composition. On scenes with no `char:` the same rule holds: action
  and scene, not a described face.
- **Pin the setting to the correct culture and century with concrete named nouns** — the
  action stays free but the _world_ around it must be historically specific, or the model
  invents generic/wrong-culture props. Name the extras' dress and **faces** (their ethnicity),
  the exact architecture, the banners and weapons, and forbid the neighbouring culture's
  version (no Qing armor on Đại Việt troops, no European faces on Asian soldiers, no
  European/Gothic tower in Thăng Long). This matters most in a two-culture comparison, where
  the model pulls the more common culture into the rarer one. See **Concrete historical
  detail** in [ai-generation.md](ai-generation.md).
- **Never restate what the template already says.** The templates in
  [lib/replicate-image.mjs](../scripts/lib/replicate-image.mjs) already cover art style,
  supporting-cast stylisation, "ordinary soldiers wear plainer gear than the commander",
  composition and framing, negative space, and the generic negatives. Repeating any of that
  here buys nothing and eats a hard character budget: Seedream rejects the whole prompt past
  4000 chars, and template + no-text policy leave roughly **670 chars for char-lock, 615 for
  face-lock, 590 for multi-character** (less if `STYLE_DNA` is longer than the default).
  `generateSceneImage` throws with the exact count when a prompt overflows. Spend those chars
  only on what changes scene to scene. See **Prompt budget** in
  [ai-generation.md](ai-generation.md).
- **Name every character the narration names.** A scene whose narration talks about two people
  gets `char: first-id, second-id` and a prompt that places them — "the first character … on
  the left, the second character … on the right". With one id on a two-person narration the
  model invents the second figure and copies the first one's face onto it. The template maps
  reference N to the Nth character in the prompt, so keep prompt order and `char:` order the
  same, and give each their own side of the composition.

Example — narration "Nhà Tây Sơn nổi dậy, nhanh chóng tiến vào Thăng Long..." with
`char: quang-trung` → `prompt: leading the army forward on a rapid northern march, arm raised
rallying the troops, banners streaming, winter terrain, wide low-angle composition` (action +
setting only; no appearance).

## What the parser emits

- `src/scene-plan.json` — `{ characters, scenes[] }`; each scene is `{ scene, from?, to?,
narration, image: { kind: 'ai'|'search', characters: [ids], prompt?, query? } }`.
- `scripts/narration-segments.mjs` — `SEGMENTS[{ scene, text }]` from each narration.

## Canonical image name

One image per scene, written by whichever step produced it (image-to-image, plain generate, or
search):

```
public/images/scene-01.jpg   public/images/scene-02.jpg   ...
```

The manifest records which it was (`AI_RECONSTRUCTION` vs a real authenticity class). Every
generated image carries an on-screen "AI phục dựng" tag. Title, cue, host pose, and the image
`prompt:` are all derived by the skill from the narration; the user does not write them.
